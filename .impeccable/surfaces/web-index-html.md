# PageScript homepage

Mode is Operate. Engineering recruiters and developers arrive to try the compiler and see how it fits an agent workflow.

## Direction contract

THESIS
The homepage is a working compiler with one ready example. The first screen makes the input, action, and HTML result easy to scan.

OWN-WORLD
Wayfinding uses navy signs, cool blue-gray work surfaces, and yellow for Render. Barlow Semi Condensed sets the large type, Barlow labels the controls, and IBM Plex Mono sets the source.

STORY
A visitor can edit the example, download the HTML, and get the agent skill beside a copyable prompt. The preview shows a note when the source has changed or the compiler needs attention. A failed render keeps the last output visible. The examples table opens each sample in the same editor and links to its hand-written HTML for the token comparison.

FIRST VIEWPORT
A plain PageScript wordmark and compact title sit above the editor and wider result. Render sits next to the source filename. Download HTML sits above the paper comparison. On a phone the panels stack with Render in reach.
